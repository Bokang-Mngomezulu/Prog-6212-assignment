# RaceDay Event Management API

---

## 📝 System Description
**RaceDay** is a RESTful API and relational database management system built to streamline the setup, management, and tracking of endurance sporting events (including running, cycling, and walking)[cite: 1, 2]. The platform automates administrative tasks for event coordinators while providing participants with a centralized hub to register for events, inspect course categories, and track their official race times[cite: 1].

---

## 👥 User Roles

The system operates using two distinct user access roles:

* **Organiser:**
  * Creates, updates, and deletes race events and location details[cite: 1].
  * Configures event-specific categories (e.g., 5km, 10km, 21km, 50km Cycle) along with entry fees and capacity limits[cite: 1].
  * Views event enrolment lists and records participant finish times and final positions[cite: 1].

* **Participant:**
  * Browses all public events, locations, schedules, and live weather conditions[cite: 1].
  * Registers/enrols for specific event categories[cite: 1].
  * Views personal event registration history and recorded completion times/results[cite: 1].
